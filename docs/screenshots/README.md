# LOKAL visual assets

These files support the [LOKAL product README](../../README.md). Keep their relative paths unchanged when uploading the documentation to LOKAL-Downloads.

## How the visuals were made

- **Web interface captures:** current LOKAL HTML, CSS, JavaScript, and bundled assets rendered in a fresh browser with isolated, fictional API fixtures. No real teacher account, student records, database, or existing browser profile was used.
- **Native interface captures:** current compiled LOKAL controls rendered in an isolated, disconnected demonstration harness. They show the application content without the surrounding PowerPoint/Windows desktop. Some options/help images frame selected actual components instead of the entire window; native region printing can differ from on-screen rounded geometry. These are interface renders, not evidence of a live classroom or successful backend action.
- **Command-guide illustrations:** diagrams based on current ribbon/menu commands and LOKAL icons. Each illustration explicitly says it is not a screenshot. The PNG files are used by the README; matching SVG files are editable sources.
- **Activity countdown:** a previously generated isolated layout-verification capture. It contains only the countdown control, not classroom records.

Demo names, classes, codes, answers, and balances are fictional. Reserved example addresses are not usable classroom joining links. Official product/authorship credits already present in the interface are retained.

Screenshots document selected states: registration shows its first step, student answering shows Multiple Choice, and the detailed browser activity report shows Word Cloud. Layout may differ with release version, viewport, Windows display scaling, or open/closed activity state.
