INSTALLATION SUMMARY

This setup checks the computer and installs only components that are missing
or need an update:

  - LOKAL classroom server
  - LOKAL Microsoft PowerPoint add-in
  - LOKAL Server Status tray application
  - Microsoft .NET Framework 4.8, only if missing
  - Microsoft Visual Studio Tools for Office Runtime, only if missing

OFFLINE INSTALLATION: All LOKAL files, Microsoft .NET Framework 4.8, and the
Visual Studio Tools for Office Runtime are included in this installer. Internet
is not required to install. Internet is needed only to obtain future installer
updates or use LOKAL online features. Microsoft PowerPoint must already be
installed. Save and close PowerPoint before continuing.
